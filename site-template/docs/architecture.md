# Architecture & layout

## Three levels

- **Level 1** — `index.html`: topic cards (newest edit first) + search. *Generated.*
- **Level 2** — `topics/<slug>/index.html`: topic overview + its experiment list.
- **Level 3** — `topics/<slug>/<NN>/index.html`: one experiment write-up (`실험 N`).

## Directory tree — who owns what

```
index.html                     GENERATED by the server on every write
data/topics-meta.json          GENERATED (via API: new-topic / set) — per-topic metadata
data/search-index.json         GENERATED — one entry per topic and per experiment
AGENTS.md  docs/               MANAGED — copied from the git repo on every server start
assets/                        MANAGED — shared CSS, vendored markdown-it, components/
client/                        MANAGED — aireport CLI, SKILL.md, install.sh for clients
topics/<slug>/index.html       AUTHORED overview island; experiment list between the
                               EXP-LIST markers is GENERATED
topics/<slug>/<NN>/index.html  AUTHORED — the experiment page
topics/<slug>/<NN>/assets/     AUTHORED — figures, *.vol.json volumes
.history/                      previous version of every overwritten file + log.jsonl (not served)
```

"Managed" files are overwritten from the repo (`site-template/`) whenever the server
restarts — change them in git, not on the server.

## Single-File HTML + Data Islands

A page's content lives in inert `<script>` blocks (a `<script>` with a non-JS `type` is a
data block the browser ignores):

| Island | Rendered by | Into |
|---|---|---|
| `<script type="text/markdown" data-md>` | `report-islands.js` + markdown-it | `<div class="prose">` |
| `<script type="application/json" class="metrics-island">` | `report-islands.js` | interactive metrics table |
| `<script type="application/json" class="vol-island" data-src=…>` | `volume-viewer.js` | 3D slice overlay viewer |

Renderers insert their output **after** the island and leave the island in place, so the
browser editor can save the page with islands intact (rendered blocks are stripped).

## Naming & path rules

- `slug` = lowercase ASCII kebab-case (`liver-tumor-seg`); `NN` = zero-padded (`01`, `02`, …).
- Relative asset prefix depends on depth: topic page → `../../assets/`; experiment page →
  `../../../assets/`. The page's own files are `assets/<file>` (relative to the page).
- `markdown-it.min.js` loads **before** `report-islands.js` (both `defer`).
- Nothing may point at the local filesystem (`file://`, `/home/…`, `/mnt/…`): copy the file
  into the page's `assets/`.

## Server

`server/app.py` in the git repo (stdlib Python, runs in Docker). API summary in its header;
`aireport` wraps it. Every write keeps the old file under `.history/`, bumps the topic's
`edited` date (KST) and regenerates the indexes. The whole site is snapshotted nightly to
the NAS (`/mnt/ai-platform-report/snapshots/`).
