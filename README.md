# ai-platform-report

Reports and write-ups for the Oncosoft AI platform: experiment results,
evaluation summaries, and related documentation.

## Structure

```
ai-platform-report/
└── README.md
```

## Usage

Clone the repository:

```bash
git clone git@github.com:jmleeonco/ai-platform-report.git
cd ai-platform-report
```

Add new reports under a descriptive, kebab-case directory and commit them
with a short summary of what changed.
